# Interview Preparation Study Guides

This collection turns scattered interview notes into a practical path from language fundamentals to senior-level architecture and cloud discussions. Each guide explains the ideas, trade-offs, and questions most likely to come up in a real interview.

## Recommended study order

Work through the guides in order, or jump to the area you need to strengthen:

1. [Study roadmap and interview strategy](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/00-study-roadmap.md) — Start here for a realistic preparation plan, revision rhythm, and advice on presenting your experience clearly.
2. [C# language and code quality](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/01-csharp-language-and-quality.md) — Reinforce the language fundamentals behind maintainable production code, including collections, generics, memory, and clean coding practices.
3. [Data structures and algorithms](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/02-data-structures-and-algorithms.md) — Practise the structures, complexity analysis, sorting, searching, heaps, and problem-solving patterns used in coding rounds.
4. [.NET and ASP.NET Core](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/03-dotnet-and-aspnetcore.md) — Understand the runtime and web framework topics that distinguish a confident .NET developer: DI, middleware, configuration, hosting, and performance.
5. [Web APIs, HTTP, and identity](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/04-web-apis-http-and-identity.md) — Learn how to design reliable APIs and explain HTTP, REST, authentication, authorization, tokens, and security decisions.
6. [EF Core, LINQ, and SQL Server](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/05-efcore-linq-and-sql.md) — Prepare for data-access questions with practical coverage of querying, tracking, relationships, transactions, indexes, and SQL performance.
7. [Architecture and design patterns](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/06-architecture-and-design-patterns.md) — Build a vocabulary for discussing SOLID, layering, common patterns, and the trade-offs behind an architecture.
8. [Concurrency, threading, and async](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/07.1-concurrency-threading-and-async.md) — Make asynchronous and concurrent code easier to reason about, from tasks and locks to cancellation and synchronization primitives.
9. [System design and distributed systems](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/08-system-design-and-distributed-systems.md) — Work through the decisions behind scalable systems: consistency, caching, messaging, resilience, observability, and failure handling.
10. [Microservices, modular monoliths, and distributed systems](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/09.1-microservices_modular_monolith_interview_tutorial.md) — Compare service boundaries and modular designs so you can explain when complexity is justified and when it is not.
11. [JavaScript interview questions](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/09-javascript-interview-questions.md) — Review the language and browser concepts that frequently appear alongside backend and full-stack interviews.
12. [React.js and Next.js interview questions](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/10-react-nextjs-interview-questions.md) — Prepare for component design, rendering, state, data fetching, and the practical trade-offs of modern React applications.
13. [Angular interview questions](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/11-angular-interview-questions.md) — Cover Angular architecture, components, services, RxJS, forms, routing, and the patterns used in enterprise frontends.
14. [Azure DevOps, Docker, and Kubernetes / AKS](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/12-azure-devops-docker-kubernetes.md) — Connect application delivery to the platform: containers, pipelines, deployments, orchestration, and operational concerns.
15. [Azure cloud administration for backend developers](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/13-azure-cloud-administration-for-backend.md) — Get a developer-friendly overview of Azure networking, identity, compute, storage, monitoring, and day-to-day administration.
16. [Questpond employer-specific interview questions](https://github.com/Khairultaher/Interview-Prep/blob/main/study-guides/15-questpond-employer-interviews-and-full-pdf.md) — Finish with a broad question bank that connects common employer-style questions to the focused explanations in the other guides.
